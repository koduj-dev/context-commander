Text expansion

The kit is measured in the longer language

Measured across the whole catalogue, German runs 126% of English and is the longest of the six; Chinese runs 44% and is the shortest. Both ends matter: a component that only fits English breaks on the left of the two comparisons, and one whose spacing was tuned for long Latin text reads as empty on the right. The same markup, three times — if a column breaks, the component is wrong, not the translation.

Nothing is pinned to a width that only fits English: table headings wrap instead of clipping, badge rows wrap, the status label grows past its minimum, and numbers and dates go through the locale rather than being concatenated — 2.4 GB and 2,4 GB are the same value. The Chinese column is also where the font stack is visible: Inter carries no Han glyphs, so if that column renders in a different face from its neighbours the platform fallback list is wrong.

Rules this kit enforces

Pink is the context you are in. Violet is context you inherit. That is the brand's one semantic rule and it holds on every screen — the nav rail, the scope rails, the override badges.
Never fake a backend capability. If an operation does not exist, the control is absent or disabled with a reason. A mockup that promises removal, rotation or SSO would be a lie the implementation has to pay for.
Domain primitives are not automatically navigation. Artifacts, events, conversations and history objects appear where they answer a management question, not because a table exists.
No inline styles on pages. If a layout need recurs it gets a utility class here. A hundred private decisions is how a kit turns back into a pile of pages.
