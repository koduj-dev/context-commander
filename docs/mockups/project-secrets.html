How a secret is used

An agent never receives the value. It passes the reference, and the server resolves it at the moment it acts.

artifact.write content: "deploy with ${{secret://project/github-token}}"\n → server resolves, uses, and never echoes it back
Resolve is privileged and separately audited. The audit records that a resolution happened — never what it returned.
