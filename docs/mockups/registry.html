How agents use this

skill.search query: "review" → latest_version_id, latest_checksum skill.get skill_version_id → content, verified against checksum

An agent remembers the checksum it loaded and compares on a later search. It re-downloads only when the skill actually changed.

Supply chain

Every version is immutable and carries a SHA-256 of its packaged content, verified on every read. Content that no longer matches is refused rather than served.

Trust status is unverified for everything published locally. Signing and an approval workflow are not built yet — the badge says so instead of implying a check that does not happen.
