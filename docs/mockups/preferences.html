How it works underneath

The server never sends a formatted string. It sends the value; the interface reads it.

"created_at": "2026-09-13T12:05:22Z" "size_bytes": 2400000000
A server that returned "2.4 GB" would have made this choice on the user's behalf — in a language it guessed at, in a timezone it does not know.
