Security review

Run before tagging a release. Stop at the first item that fails and report it rather than continuing.

  1. No credential-shaped strings in any changed file.
  2. Every new endpoint has an authorization check in the domain service, not the adapter.
  3. New tables have an RLS policy and a test that fails when the policy is removed.
  4. Migrations are reversible, or say in a comment why they are not.
To change this, publish v5. Editing a published version is impossible by design.
