# 0008. License: GNU AGPL-3.0

## Status

Accepted

## Context

The original plan draft justified AGPL-3.0 as protecting the project from a competitor running a
competing SaaS on it unmodified. That claim is wrong and was flagged by review round 1 (§4):
AGPL does not prohibit commercial use, does not prohibit forking or rebranding, and does not
prohibit running a competing service. Shipping an incorrect license rationale in the repo would
misinform contributors and users about what the license actually does.

## Decision

Context Commander is licensed under the GNU Affero General Public License v3.0 (`LICENSE`,
verbatim from gnu.org).

**What it actually does**: it is a *network copyleft* license. Anyone who runs a modified version
of Context Commander as a network service must make the corresponding source code of those
modifications available to the users of that service. It closes the "SaaS loophole" in the regular
GPL (running modified GPL code as a service isn't "distribution," so GPL alone wouldn't require
sharing the modifications) — that is the entire mechanism.

**What it explicitly does not do**:

- does not prohibit commercial use,
- does not prohibit running a competing hosted service (that service's operator just has to share
  their modifications back),
- does not prohibit forking or rebranding.

A future official client SDK (if one is built) may use a separate, more permissive license
(MIT/Apache-2.0) so it can be linked into closed client applications — that is a distinct decision,
tracked separately, not decided by this ADR.

## Consequences

- README, `SECURITY.md`, and any future marketing copy state the license this way — "protects
  against a competing SaaS" is not to be reintroduced.
- Source file headers (once added) reference AGPL-3.0.
